## About

Moonbrew Study Island is a single-page study timer with a cozy pastel-goth Halloween theme.
You pick a cute companion, start a Pomodoro session, and fly across a floating island map as your focus time progresses.

No accounts are needed. Your progress is saved locally in the browser.

---

## Features

- Custom Pomodoro timer
- Study and break time inputs
- Start, pause, and reset controls
- Pixel-style character selection
- Cute cats, dogs, and human companions
- Flying broom island progress map
- Unlockable witchy destinations
- Local study stats saved with `localStorage`
- Animated stars, clouds, fog, pumpkins, ghosts, lanterns, and sparkles
- Celebration animation and sound when a focus session ends

---

## How To Run

1. Download or clone this project.
2. Keep these files in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
3. Open `index.html` in your browser.

That is it. No install step, build tool, or framework is needed.
