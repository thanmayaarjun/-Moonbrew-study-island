# 🌙 Moonbrew Study Island 🧹

A cute witchy Pomodoro study companion with cozy Halloween vibes, pixel-art characters, and a floating island map.

🎃 [Watch the demo video](./assets/moonbrew-study-island-demo.mov)

## Features

🎨 Built with HTML, CSS, and vanilla JavaScript  
⏳ Custom Pomodoro study and break timer  
🧙 Pixel-style character selection  
🐈 Cute cats, dogs, and magical human companions  
🧹 Flying broom progress map  
🏝️ Unlockable witchy island destinations  
📊 Study stats saved with `localStorage`  
🎉 Celebration animation and sound when a session ends  
📱 Responsive cozy game-style layout  
💜 Pastel goth Halloween color palette  

## Animations Include

⭐ Twinkling stars and shooting stars  
☁️ Drifting pixel clouds and fog  
👻 Floating ghosts  
🎃 Wiggling pumpkins  
🏮 Swaying lanterns  
🧪 Potion bubbles  
🐾 Character blinking and idle bounce  
🧹 Flying broom movement  

## Run

Open `index.html` in your browser. No setup required.
